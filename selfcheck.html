Response Headers · Hardening tips only, not counted as issues

Where to copy (pick either): (1) Run curl -sI https://your-domain.com in your terminal and copy the full output; (2) In Chrome, press F12 → Network → reload the homepage → click the first request → toggle Raw under Response Headers and copy. Remove any lines containing cookie or authorization before pasting.

Analyzes only the final response header block; does not check TLS certificates, redirect chains, or live sessions. Either a valid frame-ancestors directive or X-Frame-Options passes clickjacking protection.
