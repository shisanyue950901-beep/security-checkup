Supabase RLS 自检

把 migration / schema SQL 贴进来，扫 USING (true)、缺 TO 子句的策略、没开 RLS 的表、以及写在代码里的密钥。 全部在浏览器本地计算：不上传、不联网、刷新即丢，代码不出你的机器。

扫出问题了？

这是规则匹配，只覆盖 RLS 与密钥这两类。人工复核会继续看：越权路径（IDOR / BOLA）、会话与鉴权、注入与文件处理、 付费接口的额度与 spend cap、webhook 验签、存储桶权限。每条问题带文件行号证据和可粘贴的 AI 修复提示词。
