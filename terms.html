2. The service

We provide a fixed-scope, static source-code security checkup for web applications: a manual, cross-file review of code you provide, delivered as a written report with severity-rated findings, file-and-line evidence, remediation guidance, and one re-check of the same scope after you apply fixes.

The service is a static review only. It is not a penetration test, does not include dynamic or runtime testing, does not attack or probe any live system, and is not a compliance certification (including SOC 2, ISO 27001, PCI DSS, or HIPAA).
