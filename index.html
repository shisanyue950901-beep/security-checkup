What we check

  • Secrets & API keys shipped to the browser
  • Login, sessions, and tokens that never expire
  • "Admin" checks an attacker can fake
  • IDOR / broken access control — users reading each other's data
  • Database rules left open (Supabase RLS, Firebase rules)
  • XSS and injection paths
  • File uploads that write to your web root
